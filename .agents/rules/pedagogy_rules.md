# 教育的指導 & コーディング規約 (Pedagogy & Coding Rules)

プログラミング教室の生徒さんがコードを読み、変更を加えながら学べるようにするための具体的な実装規約です。

---

## 1. コメント記述ルール
* **3D座標・回転・物理計算:**
  * 「なぜこの計算をするのか」を1行添える。
  * 例: `// ボールの最高到達点（peakHeight）から、重力加速度を用いて上昇時間 tUp を算出`
* **状態管理 (State Pattern):**
  * `BallState` や `PlayerAction` のように、現在の状態（ドリブル中、空中、着地等）を明示的な定数/Enumで管理する。

---

## 2. エラー予防と安全ガード
* クラス間連携（例: `Player` から `Ball` や `Court` の参照）では、生成順序の違いで `undefined` が発生しないよう、初期化順序の整合性とガード節を設ける。
* 新しいイベントリスナーを追加する際は、メモリリークや重複登録を防ぐ。
