# 単発のボール音と接触の鳴り分け

ユーザーから「ボールは2回音が鳴るのでカットが必要かも」と連絡。追加されたボール/リング/ネット動画から単発音を作り、ゲームへ組み込む。最新ビルドと検証は[HANDOFF](../../HANDOFF.md)を参照。

## 手順

1. Downloadsの3動画をSourceAssets/Audio/BallEffectsへコピーし原本を保持。VLCで48kHz/16bit/ステレオWAVへ変換する。
2. 50ms単位のRMSで衝撃と後続ピークを調べる。ボールは最初の1.98–2.28秒だけを残し、リング2.22–2.85秒、ネット2.28–3.02秒を抽出する。
3. [prepare_effects.py](../../Evidence/audio-effects-20260920/prepare_effects.py)で開始/終了フェードと上限付き増幅を行い、原本/加工物ハッシュを保存。原本と長いWAVは上書きしない。
4. UnityへPCM/DecompressOnLoadで収録。音楽・歓声・接触の3 Sourceを共用し、追加のSourceを生成しない。
5. HoopsActorのドリブル周期は変更せず、HoopsBallから衝突相手名を渡す。分割リングの連続同時通知を75msの同種音抑制でまとめる。板/支柱はボール音を暫定使用する。
6. 実入球でネット音を1回鳴らし、Streetは既存歓声も再生。発射/失敗/成功の正弦波ビープは削除。得点・物理・カメラ・BGM選択は保持する。

## 検証と未確認

単発クリップの長さ・ピーク・出力、後続ヒットが鳴らないこと、同時のリング通知、別材質との重なり、後からの再接触、Pause/ミュート/Rを確認する。1.4秒の実ドリブルで周期相当の音数を測り、全世界の実得点ごとにネット音が一度だけ鳴ることを確認。衝突通知の音声引数だけの変更でも、既存の得点/物理回帰を再実行する。

音の自然さ・音量・残響の聴感は人間に確認を残す。床材ごとの音、板専用音、他世界の歓声は未完成。生成条件詳細は未提供、CC0とは扱わずローカル試遊のみ。

## 💡 このセッションで学んだプログラミング概念

- 単発イベントと素材長：ゲームが1回だけ命令しても素材内に2回の衝撃があれば2回聞こえる。
- 重複抑制：一つのリングに複数Colliderがあると通知は複数届く。判定を変えず、音だけを短い時間窓でまとめる。
- 同期：Pauseは短い音にも必要。停止・再開・取り消しの検査をBGMだけに限定しない。
- 再現性：抽出区間、フェード、増幅率、ハッシュがあれば同じ音を作り直せる。
