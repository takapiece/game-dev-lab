## 効果音の進め方

実物の質感が必要な音は無料素材、ゲームの合図は自作の短い音を組み合わせる。

| 音 | 方法の提案 | 狙い |
|---|---|---|
| ドリブル・床バウンド | CC0の実録音から短い単発音を選ぶ | ボールの空気感と床への接触を伝える。数種を弱く変化させ連打感を減らす |
| リング・バックボード | 金属・板の短い実音素材 | 接触場所を聞き分けられるようにする |
| ネットの通過 | 短い実音、合う素材がなければ自作 | 入球した瞬間の気持ちよさ。成功通知に同期 |
| 靴の擦れ・着地 | 実音素材。木床のGym/Arenaを中心に控えめに使う | 毎歩の大音量再生は避け、停止や切り返しを伝える |
| 成功・ステージクリア・UI | 自作の短い音階やクリック | 成功とクリアを長さ・音色で区別し、BGMと競合させない |

効果音はバウンド・成功・失敗・リリースの4つの簡易合成音。ユーザーが先にStreetのBGMを提供・選択したのでBGMの組み込みを先行し、SEとBGMの別音量・一括ミュートを用意する。効果音の差し替えは次の工程。採用曲は[Street原本記録](../../SourceAssets/Audio/Street/PROVENANCE.md)。

候補は2026-09-20に公式配布ページの表示を確認。試聴・採用・ダウンロードはまだ行っていない。

- [Kenney Impact Sounds](https://kenney.nl/assets/impact-sounds)：CC0表示。一般的な衝撃音の候補であり、バスケ専用音が揃うと確認したわけではない。
- [BasketballBounce.wav / Blankened](https://freesound.org/people/Blankened/sounds/505628/)：CC0表示、0.254秒の単発バウンド、48kHz/16bit WAV。短いドリブル音の候補。
- [Basketball Bounce / vhschool2019](https://freesound.org/people/vhschool2019/sounds/716925/)：CC0表示、セメント上のボール、2.5秒WAV。屋外音の候補。
- [Freesoundのライセンス説明](https://freesound.org/help/faq/)：サイト全体で同じ条件ではないため、採用する個別素材の表示と同梱条件を記録する。

## BGMの共通方針

4曲を別々に生成する。まずStreetを1曲作り、ゲーム内のテンポに合うことを確認してから残り3曲へ進む。歌・掛け声・環境音・ボールの音は入れず、ゲーム内の効果音に任せる。長いイントロや大きな展開を避け、反復しても疲れにくい曲にする。

下の各ブロックをそのままGeminiへ渡せる。長さは利用中の生成機能に合わせる。ここで示すテンポは曲調の希望であり、生成結果の保証ではない。ループの継ぎ目は受領後に音源を確認し、必要なら編集して整える。

### 1. Street — 最初に作る曲

```text
3Dバスケットボールゲーム「HOOPS: WORLD TOUR」のStreetステージ用に、オリジナルのインストゥルメンタルBGMを作ってください。

舞台は明るい昼の街角の屋外コート。気軽に何度もシュートしたくなる、軽快で少しクールなヒップホップ＋ファンク。目安は102 BPM、4拍子。タイトなドラム、弾むエレキベース、短いエレクトリックピアノのコード、控えめなギターカッティング。短い覚えやすいモチーフは入れるが、主旋律を前に出しすぎない。

最初からグルーヴが始まる、繰り返し再生用のゲームBGM。大きな盛り上がり、長いイントロ、ブレイク、最後の決め、フェードアウトを避け、終わりから冒頭へ自然につながる構成にする。

歌詞、歌声、ラップ、掛け声、観客、環境音、ボール音、靴音、ゲーム効果音は入れない。高音のハイハットや低音を強くしすぎず、ドリブル音と得点音が聞こえる余白を残す。既存曲の引用ではなく、このゲーム用の新しい楽曲にする。
```

### 2. Gym — 練習のリズム

```text
3Dバスケットボールゲーム「HOOPS: WORLD TOUR」のGymステージ用に、オリジナルのインストゥルメンタルBGMを作ってください。

舞台は木床と高い窓のある明るい体育館。練習に集中できて、少しずつ調子が上がる軽快なファンク＋ブレイクビーツ。目安は112 BPM、4拍子。乾いたドラム、丸く弾むベース、短いオルガンまたはエレクトリックピアノ、控えめなミュートギター。短いモチーフで統一感を出し、メロディーは少なめ。

最初から安定したグルーヴが始まり、繰り返しても疲れないゲーム用ループ。長いイントロ、大きなブレイク、最後の決め、フェードアウトは避ける。歌、ラップ、掛け声、観客、環境音、ボール音、靴音、効果音を入れない。木床のバウンド音やシューズ音をゲーム側で重ねるので、音数と高音を抑え、隙間を残す。既存曲を引用しない。
```

### 3. Arena — 晴れ舞台

```text
3Dバスケットボールゲーム「HOOPS: WORLD TOUR」のArenaステージ用に、オリジナルのインストゥルメンタルBGMを作ってください。

舞台は観客席と照明塔がある大きなアリーナ。プレーヤーが晴れ舞台に立つ高揚感を、スポーツ向けのエレクトロファンクで表現。目安は120 BPM、4拍子。歯切れのよいドラム、太すぎないシンセベース、短いブラス風シンセ、少量のクラップ。勇ましいが威圧的ではなく、シュートを決めたくなる前向きな雰囲気。

最初から曲の本体が始まる反復用ゲームBGM。巨大なドロップや長い盛り上げ、長いソロ、最後の決め、フェードアウトは不要。勝利ファンファーレではなく、プレイ中ずっと流せる一定の熱量にする。歌、掛け声、観客の歓声、環境音、ボール音、ゲーム効果音を入れない。得点の効果音が主役になれる余白を残す。既存曲を引用しない。
```

### 4. Neon — 最後の夜のコート

```text
3Dバスケットボールゲーム「HOOPS: WORLD TOUR」のNeonステージ用に、オリジナルのインストゥルメンタルBGMを作ってください。

舞台は青とピンクのネオンが光る夜のコート。最後のステージらしい高揚感と、夜の街のクールさが共存するシンセウェーブ＋エレクトロファンク。目安は124 BPM、4拍子。弾むシンセベース、輪郭のあるドラム、短いきらめくアルペジオ、薄い温かなパッド。暗く恐ろしい方向ではなく、スタイリッシュで楽しい曲。

最初から一定のグルーヴを保つ、繰り返し再生用ゲームBGM。長いイントロ、激しいドロップ、急な転調、最後の決め、フェードアウトを避け、終わりから冒頭へ自然につながる構成。歌、ラップ、掛け声、観客、街の環境音、ボール音、ゲーム効果音を入れない。高音を鋭くしすぎず、重低音を詰め込みすぎない。ドリブルと得点の音が聞こえる余白を残す。既存曲を引用しない。
```

## 音源を受け取った後

元のダウンロードファイルはそのまま残す。ファイル名の例はbgm_street、bgm_gym、bgm_arena、bgm_neon（拡張子は生成された形式のまま）。生成日・利用サービス/モデル・プロンプトも記録する。音源の長さ、継ぎ目、音量、生成時の利用条件を確認して採用する。

実装時にはSEとBGMを別音量にし、ミュート、Pause、ステージ切替、全体再プレイで音が重ならないことを検証する。BGMは効果音より控えめな音量から調整する。今回の文書作成では購入・外部送信・生成サービスの操作・公開は行わない。

## 追加依頼：実音の効果音とゴール後の歓声

2026-09-20、ユーザーが現行SEをチープと評価し、ゴール後のカメラ演出への「完成」を希望。文脈から「歓声」と解釈した。ユーザーはGoogle Flowでの効果音生成を質問している。まだ素材の生成/受領/SEの差し替えは行っていない。

コード確認では、現行SEは4種の正弦波で、床・リング・板の接触にも同じBounceが鳴る。単に音量を変えるだけでは材質の区別が付かない。次の実装では床/リング/板を衝突相手から鳴り分け、成功の電子音をネット音と歓声へ置き換える。現行の発射/失敗の電子音も削除または実音へ変更する方向。

### Google Flowで作る方法

Google公式はFlow/Veoで動画に効果音・環境音を生成できると案内している。[音声生成の案内](https://blog.google/innovation-and-ai/products/flow-video-tips/)、[Veo 3.1の音声対応](https://blog.google/innovation-and-ai/products/veo-updates-flow/)、[現在の対応モデル](https://support.google.com/flow/answer/16352836?hl=en)。今回確認できたのは映像と音声の生成であり、独立した効果音ファイルだけを直接生成/書き出しできると確認したわけではない。

音声対応モデルで短い動画を作り、MP4等を受け取った後に音を抽出してゲーム用に切り出す。ゲーム映像に歓声を焼き込むのではなく、独立した音として成功イベントへ同期する。生成サービスの操作やクレジット消費はこちらでは行わない。

### Flow用：Streetの得点後の歓声（まずこれを1本）

```text
8秒の固定カメラ映像。昼の屋外バスケットコートの脇で、5～8人の大人の友人がコートのプレーを見ている。音響を最優先したリアルな素材映像。

音声：冒頭は静か。1秒付近で画面外のシュートが決まったことに反応し、短く自然な「おおっ！」という歓声と数回の拍手が起こる。反応はすばやく立ち上がり、約2～3秒で自然に収まる。最後は静かにして余韻を残す。小さな屋外の集まりらしい近すぎない距離感。大スタジアムの群衆や長い絶叫ではない。声が割れない、耳に刺さらない、適度な迫力。

音楽、実況、会話、意味のある文章、ホイッスル、車、風、ボール音、靴音、電子音は入れない。歓声と拍手だけを分離して使いやすい、クリーンな音声。字幕や文字表示なし。映像は固定で、ズームやカットは不要。
```

### Flow用：単発のドリブル音

```text
8秒の固定クローズアップ映像。静かな屋外の硬いバスケットコートで、大人の手が空気の入ったバスケットボールを一度だけ床へ強く突き、跳ね返ったボールを手で受け止める。動作は2秒付近の1回だけ。

音声を最優先。バスケットボール特有の低い空洞の響きと、短く乾いたゴムの接触音が重なる。自然な重さがあり、爆発音や電子音ではない。接触の前後に静かな余白があり、残響は短い。反復ドリブル、転がり、足音、声、音楽、風、環境音、字幕は不要。
```

### Flow用：リングへの接触音

```text
8秒の固定クローズアップ映像。静かなバスケットコートの金属リングに、バスケットボールが2秒付近で一度だけ当たり、画面外へ離れる。

音声を最優先。ボールの柔らかい衝撃と、厚い金属リングの短い「ガン」という共鳴。高いベルや長いチャイムではない。接触は1回だけ。床への落下音や追加の接触は鳴らさない。音の前後に静かな余白を残す。声、音楽、歓声、風、電子音、字幕は不要。
```

### Flow用：ネットを通る成功音

```text
8秒の固定クローズアップ映像。静かなバスケットコートで、バスケットボールが2秒付近でリングの中央から入り、白いネットを一度だけ通り抜ける。リングとバックボードには当たらない。

音声を最優先。ボールがネットを押し広げる、短く気持ちのよい「スパッ、シュッ」という布と紐の擦れる音。リアルで、電子的な成功チャイムではない。音の前後に静かな余白。床への落下音、声、歓声、音楽、風、字幕は入れない。
```

### ゲームへの合わせ方

- 歓声は実際の得点にだけ発火し、入力のグリーン判定では鳴らさない。
- 通常成功は短い反応、3本目のクリアは少し強い拍手。Streetは少人数、Arenaは大きな客席という違いを付ける。
- 得点後の2.6秒/3秒のカメラ演出に収め、操作再開へ長く重ねない。ダンクでは着地待ちとカメラ開始のタイミングも確認する。
- BGMの音量低下は既存処理を活用する。Pause/ミュート/R/ステージ切替で歓声が残らないようにする。
- 単発の接触音は無料の実録素材でも用意できる。Flowは歓声の人数や反応の調整を試す候補とし、全効果音を動画生成することは必須にしない。
