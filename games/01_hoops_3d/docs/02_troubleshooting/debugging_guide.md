# 🔍 ゲーム開発のためのデバッグ入門ガイド (Debugging Guide)

ブラウザでゲームを作っているときに「画面が動かない」「思った通りに動かない」時の調べ方（デバッグ手順）です。

---

## 1. 最も重要なツール: ブラウザの「開発者ツール（F12）」

1. **コンソールタブ (Console) を開く**:
   * キーボードの `F12`（Macは `Cmd + Option + I`）を押し、**「Console」** タブを見ます。
   * **赤文字のエラー** が出ていれば、どのファイルの何行目で問題が起きたかが一目でわかります。
2. **スタックトレースの読み方**:
   * エラーが出た場合、上から順に関数の呼び出し履歴（スタックトレース）が並んでいます。自分が書いたファイル（例: `main.js:117`）をクリックすると、該当のコード行へ直接ジャンプできます。

---

## 2. 3Dゲーム特有の「画面が真っ暗」チェックリスト

3D空間（Three.js）で画面に何も映らないときは、以下の原因を疑います：

1. **JavaScript の実行エラーで描画ループが止まっていないか？**
   * Console を確認（エラーで `requestAnimationFrame` が止まっているケースが多い）。
2. **カメラがオブジェクトの方を向いているか？**
   * `camera.position`（位置）と `camera.lookAt()`（注視点）が一致してしまっていないか、または遠すぎないか。
3. **ライト（照明）が配置されているか？**
   * `MeshStandardMaterial` は光（AmbientLight / DirectionalLight）がないと真っ黒になります。
4. **物体のサイズ・スケールが極端に大きくないか / 小さすぎないか？**
