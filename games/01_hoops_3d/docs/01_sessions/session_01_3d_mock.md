## 2. 実装した機能・コード解説

### ① 3DコートとNBAゴールのプロシージャル生成 (`src/court.js`)
* **木目コートの描画:** 外部画像を使わず、HTML5 Canvas API で木目のグラデーションと白線を動的描画し、Three.js の `CanvasTexture` として床に貼り付けました。
* **バスケットゴール:** 
  * ガラス製バックボード: `MeshPhysicalMaterial`（透明度と反射）
  * オレンジリング: `TorusGeometry`（円環）
  * ネット: `CylinderGeometry`（ワイヤーフレーム付き円錐台）

### ② 放物線シュートの物理計算 (`src/ball.js`)
シュートを打った位置 $(x_0, y_0, z_0)$ からリングの位置 $(x_g, y_g, z_g)$ までの距離に応じて、**高校物理の「斜方投射」** の公式を使って速度ベクトル $(v_x, v_y, v_z)$ を計算しています。

```javascript
// 最高到達点の高さ（peakHeight）から上昇時間と下降時間を計算
const tUp = Math.sqrt((2 * (peakHeight - origin.y)) / -gravity);
const tDown = Math.sqrt((2 * (peakHeight - target.y)) / -gravity);
const totalTime = tUp + tDown;

// 水平方向と鉛直方向の初速度
const vy = -gravity * tUp;
const vx = (target.x - origin.x) / totalTime;
const vz = (target.z - origin.z) / totalTime;
```

### ③ 2K風「グリーンリリース」シュートメーター (`src/player.js`, `src/main.js`)
* シュートボタン長押し時間を計測し、最適なリリース時間（0.55秒）との誤差を判定。
* 誤差が極めて小さい場合（Green Light）、ボールの軌道ブレをゼロにし、綺麗なスウィッシュ（ネット通過音）とチャイム音を再生します。

### ④ Web Audio API によるシンセサイザー効果音 (`src/audio.js`)
* 音声ファイル（mp3等）をダウンロードするのではなく、ブラウザの音声オシレーター（発振器）とノイズフィルターを使って**プログラム内でリアルタイムに音を合成**しています。
  * ドリブル音: 低周波サイン波（140Hz $\rightarrow$ 35Hz）の急減衰
  * スウィッシュ音: ホワイトノイズのバンドパスフィルター通過音
  * グリーンチャイム: D5, A5, D6, A6 の和音分散再生

## 3. 💡 このセッションで学んだプログラミング概念

1. **ゲームループ (Render Loop) とデルタタイム (`delta`)**:
   * パソコンやスマホの性能によってフレームレート（FPS）が変わっても、同じ速度でキャラクターが動くように、前フレームからの経過時間 `delta` を移動速度に掛けて計算します（時間補正）。
2. **オブジェクトの責務分離 (Single Responsibility Principle)**:
   * コート描画・ボール物理・プレイヤー操作・音響を別々のファイル（クラス）に分けることで、バグが起きたときに原因箇所を素早く特定できるようにしました。
3. **Web Audio API とユーザー操作制限**:
   * ブラウザは「ユーザーが画面をクリック/タップする前」に勝手に音を鳴らすことを禁止しています。そのため、スタートボタンを押した瞬間に `sounds.init()` を呼び出して音声をアンロックする仕組みを取り入れました。
