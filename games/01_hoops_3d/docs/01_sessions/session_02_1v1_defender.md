## 2. 実装した機能・コード解説

### ① 3D AIディフェンダーモデル & ステートマシン (`src/defender.js`)
* **3Dモデル生成:** プレイヤー（Lakers 紫/金）と対比させた Bulls 風のクリムゾンレッド＆ブラックジャージを着用した人型モデル。
* **行動ステートマシン (`DefenderState`):**
  * `GUARD` (マーク中): プレイヤーとゴールの間に回り込むようにスライドステップ移動。
  * `CONTEST` (シュート妨害): プレイヤーがシュートモーションに入ると、人間の反射神経を模した反応遅延（0.12秒）後に両手を上げてジャンプブロック。
  * `REBOUND` (ルーズボール): シュート後、床に弾むボールへ向かって移動。

### ② ベクトルの内分点を使ったディフェンスポジショニング
ディフェンスが「ボールマンとゴールの間」に回り込む位置を、数学のベクトル加算で計算しています。

```javascript
// プレイヤーからゴールへ向かう単位ベクトル
const toHoop = hoopPos.clone().sub(playerPos).setY(0).normalize();
// プレイヤーからクッション距離（約1.65m）ゴール側に離れた目標位置
const targetPos = playerPos.clone().addScaledVector(toHoop, this.guardDistance);
```

### ③ 幾何学によるシュートコンテスト率（Contest %）の判定
シュート時のディフェンスの妨害度を「距離」「角度（内積）」「手の高さ」から 0% 〜 100% で計算。
* `WIDE OPEN` (0〜12%): プレッシャーなし。高確率で決まり、パーフェクトリリース有効。
* `OPEN` (13〜35%): 軽微なコンテスト。
* `CONTESTED` (36〜70%): タイミング許容幅が狭まり、弾道ブレが増加。
* `SMOTHERED` (71〜100%): 激しいマーク下のタフショット。

### ④ 近接ブロック判定 & Web Audio ブロック音 (`src/ball.js`, `src/audio.js`)
* 至近距離（1.35m以内）かつディフェンダーがジャンプ最高点付近にいる場合、シュートを叩き落とすブロックが発生。
* Web Audio API のオシレーター（低音の三角波アタック）とハイパスフィルター付きノイズ（スラップ音）を合成した `sounds.playBlock()` を追加。

## 3. 💡 このセッションで学んだプログラミング概念

1. **ベクトルの内分と正規化 (Normalization):**
   * 2点間の方向ベクトルを求め、長さを 1 に揃える（`normalize()`）ことで、任意の距離だけ進んだ座標を簡単に計算できます。
2. **内積（Dot Product）による「向きの一致度」判定:**
   * 「ディフェンダーがプレイヤーの正面（ゴールとの間）に立っているか」をベクトルの内積で判定（内積が 1.0 に近いほど正面）。
3. **ゲームデザインにおける「遅延（Latency）と慣性」の重要性:**
   * AIが完璧かつ即座に動くとゲームが理不尽になります。適度な反応ディレイ（0.12秒）や移動の慣性を入れることで、「人間らしいプレイヤーが勝てるバランス」が生まれます。
