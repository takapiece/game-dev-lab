# 🎓 セッション手順書 #03: 統合学習ダッシュボード & インタラクティブコード解説辞書の構築

本ドキュメントは、第3回セッションで実装した **「統合学習ダッシュボード」「VS Code風シンタックスハイライター」「インライン数式解説」「初学者向けJS＆Three.jsホバー解説辞書」「Win/Mac完全対応起動ガイド」** の開発手順と教育的ポイントをまとめた記録です。

---

## 🎯 セッションの目標
1. 生徒・講師がフェーズごとの仕様・コード・数学・AIプロンプトをワンストップで学べる **『統合学習ダッシュボード』** を構築する。
2. 初学者がつまずきやすい専門用語（`this`, `class`, `const`, `normalize`, `dot`, `update`, `playBounce` 等）にカーソルを乗せるだけで意味がわかる **『ホバー・ポップアップ辞書』** を実装する。
3. Windows と Mac（MacBook）の両環境で100%確実に動く **『クロスプラットフォーム起動マニュアル』** を整備する。

---

## 🛠️ 今回実装した機能一覧

### 1. 統合学習ダッシュボード (`dashboard/index.html`, `dashboard.js`, `dashboard.css`)
* **フェーズ連動ナビゲーション:** Phase 1（ソロ練習）と Phase 2（1v1対戦）を切り替えると、全コンテンツがリアルタイムに更新。
* **6つの学習タブ:**
  1. **📋 概要 & 要件定義:** 各フェーズのゴール・見どころ・意思決定ログ（ADR）。
  2. **💻 ソースコード閲覧 (Code Explorer):** ファイルツリーからファイルを選び、ハイライト＆解説付きでコードを閲覧。
  3. **📐 数学 & 前提知識:** 3D座標系、斜方投射の初速度逆算、ベクトルの内分点・内積計算、Web Audio音響合成、ステートマシンの数式解説。
  4. **🤖 AI指示ガイド (プロンプト集):** AI（Gemini/ChatGPT等）へプロンプトを出す際の鉄則と「悪い例 vs 良い例」の実践的比較。
  5. **🛠️ トラブルシューティング:** ERR-001〜ERR-003 の発生現象・原因・解決手順・学び。
  6. **🎮 ライブプレイ:** ダッシュボード内でそのフェーズのゲームを直接プレビュー実行。

### 2. ソースコード閲覧の教育的拡張
* **VS Code 風シンタックスハイライター:** キーワード、Three.js型、文字列、数値、コメント、関数呼び出しを鮮やかに色分け。
* **インライン解説カード:** 放物線斜方投射、ベクトルの内分点、内積正面判定、ステートマシンなどの直下にわかりやすい解説カードを挿入。
* **クイックジャンプ目次:** 上部のピルボタンをクリックすると、重要ロジック行へスムーズスクロール。
* **ホバー・ポップアップ辞書 (Glossary Tooltip):**
  - 📘 **JS 基礎構文:** `this`, `class`, `constructor`, `const`, `let`, `new`, `return`, `import`, `export`, `if`, `else`, `switch`, `case` 等
  - 🎮 **Three.js 3D操作:** `clone()`, `sub()`, `normalize()`, `dot()`, `addScaledVector()`, `add()`, `remove()`, `lookAt()`, `getDelta()` 等
  - 📐 **数学・物理:** `Math.sin()`, `Math.cos()`, `Math.sqrt()`, `Math.atan2()`, `Math.max()`, `Math.abs()` 等
  - 🔊 **Web Audio:** `AudioContext`, `createOscillator()`, `createBiquadFilter()`, `playBounce()`, `playBlock()`, `playSwish()` 等
  - 🔄 **ゲームループ:** `update()`, `animate()`, `calculateContest()`, `tryBlock()`, `releaseShot()`, `shoot()`, `block()`, `reset()` 等

### 3. クロスプラットフォーム起動マニュアル (`SETUP_GUIDE.md`)
* Windows（PowerShell / VS Code）と Mac（ターミナル / VS Code）のOS別起動手順。
* 初学者が遭遇しやすいトラブル（npmが見つからない、音が出ない、ポート重複）のFAQ。

## 💡 このセッションで学んだプログラミング＆教育設計の概念

1. **「触ればわかる」フィードバックの即時性:**
   - 専門用語を別サイトで調べさせるのではなく、コード上の単語に触れた瞬間に「日常の例え（金型、設計図、荷物の入れ物）」で理解できる環境を作ることの重要性。
2. **データベース不要（静的ファイルベース）の堅牢性:**
   - 単に閲覧する教材データであれば、サーバーDBを作らず JSON / JS オブジェクトで管理することで、環境構築トラブルをゼロにし、誰のPCでも一瞬で動く教材になる。
3. **完全相対パスによるクロスプラットフォーム保証:**
   - Windows と Mac の違いを意識させず、スラッシュ相対パス（`./`, `../`）で統一する設計の美しさ。
