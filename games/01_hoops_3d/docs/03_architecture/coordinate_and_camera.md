# 📐 3D空間の座標系とカメラワーク (3D Coordinates & Camera)

Three.js における 3D 空間の捉え方と、ゲームで臨場感を出すカメラコントロールの仕組みを解説します。

---

## 1. 3D座標系（右手系）

Three.js は **「右手座標系（Right-Handed Coordinate System）」** を採用しています。

```
       +Y (上 / ジャンプ方向)
        |
        |
        |______ +X (右 / サイドライン)
       /
      /
    +Z (手前 / バックコート側)
```

* **X 軸 (横方向):** 画面右側がプラス（$+X$）、左側がマイナス（$-X$）。
* **Y 軸 (高さ方向):** 上方向がプラス（$+Y$）、床面が $Y=0$、リングの高さは $Y=3.05\text{m}$。
* **Z 軸 (奥行き方向):** バスケットゴールが奥（$-Z$ 側）、手前のセンターサークル側がプラス（$+Z$）。

---

## 2. 3種類のカメラモードの実装 (`src/main.js`)

ゲーム内では `C` キー（または画面上の「🎥 CAM」ボタン）で以下の3つの視点を切り替えられます：

### ① 2K Broadcast 視点 (放送・テレビ中継風)
* **位置:** サイドライン斜め上 $(X \approx 7.5, Y \approx 5.2, Z \approx 6.5)$
* **特徴:** プレイヤーの動きに合わせてカメラが自然にパン・チルトし、コート全体とリングの位置関係が最も見やすい視点。

### ② Follow 視点 (TPS / 背後追従)
* **位置:** プレイヤーの背後 $3.8\text{m}$、高さ $2.2\text{m}$
* **特徴:** プレイヤーの向いている方向にカメラが追従し、まるで自分がコートに立っているかのような没入感。

### ③ High 視点 (戦術トップアングル)
* **位置:** 上空 $10.5\text{m}$
* **特徴:** コート全体を俯瞰し、ディフェンスの位置やパスコースを把握しやすい視点。

---

## 3. カメラのスムーズな追従 (線形補間: Lerp)

カメラがカクカク動かないように、**線形補間（`lerp`）** を使って滑らかに追従させています：

```javascript
// 目標位置に向かって毎フレーム 8% ずつ滑らかに近づける
this.camera.position.lerp(targetPos, 0.08);
this.camera.lookAt(this.cameraTarget);
```
