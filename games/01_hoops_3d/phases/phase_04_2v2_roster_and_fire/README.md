# 🏀 Phase 4: 2v2 フルゲーム対戦・選手カード編成・協調AI・ON-FIREモード

本スナップショットは、HOOPS 3D の **Phase 4 完了時点の独立実行可能コード** です。

---

## 🎯 Phase 4 の主要機能

1. **🏀 2v2 フルゲーム対戦 ＆ 協調AI:**
   - オフェンス2人（自分＋味方AI） vs ディフェンス2人（Jordan & Pippen）。
   - マンマークと、ペイントエリア（ゴール下）侵入時のヘルプディフェンス・ダブルチームをAIが自律連携。
2. **🎴 選手カード ＆ ロスター編成（データ駆動型設計）:**
   - 選手ごとに 3PT（シュート力）、SPD（走力）、DEF（守備力）をステータス数値化。
   - 試合前に好きな選手コンビ（Kobe & LeBron、Chef & LeBron など）を選択して出撃可能。
3. **🔥 ON-FIRE（覚醒）モード ＆ 炎パーティクル演出:**
   - 3連続シュート成功（Streak 3）で発動。
   - Three.js パーティクルによる燃え盛る炎をまとい、移動速度1.2倍、シュート緑ゾーンが1.45倍にブースト！
   - Web Audio による豪快なエレクトロニック・アルペジオ（`playOnFire`）が響き渡る。
