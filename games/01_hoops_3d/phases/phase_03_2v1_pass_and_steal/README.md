# 🏀 Phase 3: 2v1 オフェンス（味方AI・パス・操作キャラ切替・スティール・24秒ショットクロック）

本スナップショットは、HOOPS 3D の **Phase 3 完了時点の独立実行可能コード** です。

---

## 🎯 Phase 3 の主要機能

1. **⛹️‍♂️ 味方AI（Teammate） & オフボール・スペーシング:**
   - Lakers パープルジャージの味方プレイヤー（AI）。
   - ボールハンドラーと重ならないよう、反対側の3ptライン外側（ウィング〜コーナー）へ自律移動。
   - 足元にパルスする「PASS TARGET」リングエフェクトを表示。
2. **🏀 パス機能 & 操作キャラクターの動的切り替え（Pass & Switch）:**
   - `P` キー（PC）または `🏀 PASS` ボタン（モバイル）で味方へパス。
   - ボールが味方に到達した瞬間、操作対象が味方に切り替わり、元のプレイヤーは自動的にオフボールAIモードへ移行。
3. **🚫 スティール（Steal） & パスカット判定:**
   - ディフェンダーの正面至近距離（0.85m以内）に突っ込むとボールを叩かれるオンボールスティール。
   - パス軌道上にディフェンダーがいる場合のパスカット。
4. **⏱️ 24秒ショットクロック & ブザー音:**
   - 攻撃開始時に 24.0秒からカウントダウン。
   - 0秒になるとバイオレーションブザー音が鳴りターンオーバー。
