🏀 PHASE 3: 2v1 PASS & SHOT CLOCK
味方AI・パス・操作キャラ切替・24秒ルール
Lakersのチームメイト（味方AI）と連携し、Bullsの屈強なAIディフェンダーを崩そう！
味方へのパスが通ると操作キャラクターが瞬時に切り替わります。24秒以内にシュートを決めよう！
💻 PC操作 (Keyboard)
  • WASD : ドリブル移動
  • P / K : 味方へパス ＆ 操作キャラ交代
  • SPACE (長押し) : シュートメーターチャージ
  • SPACE (離す) : 緑ゲージの頂点でリリース！
  • SHIFT : ダッシュ移動
  • C : カメラ切替（中継 / 追従 / 俯瞰）
  • R : 24秒リセット・初期配置
  • ESC / M : ポータル目次へ戻る
📱 スマホ・タッチ操作
  • 左スティック : スライドで自由にドリブル移動
  • [PASS] ボタン : 味方へパス ＆ 操作キャラ交代
  • [SHOOT] ボタン長押し : チャージ開始
  • [SHOOT] 離す : 緑ゾーンでシュート！
  • [DASH] : 高速ダッシュ
  • [CAM] / [RESET] / [MENU] : 画面右上・下部
💡 Phase 3 攻略のコツ
・ディフェンダーが近づいてきたら [P] キーでフリーの味方にパス！
・ディフェンダーの正面に突っ込むと スティール され、コース上にパスを出すと パスカット されます。
・24秒ショットクロック が 0 になるとブザーが鳴りターンオーバーになります。
