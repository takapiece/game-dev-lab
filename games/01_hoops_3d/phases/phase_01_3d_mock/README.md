# 🏀 Phase 1: 3Dハーフコート & 放物線シュート 初期モック

このディレクトリは、**第1回開発セッション完了時点の完全独立スナップショット** です。

## 🎯 このフェーズでできること
- 3D木目バスケットコート＆NBAゴールの生成
- プレイヤーの移動（WASD/タッチ）＆ドリブルアニメーション
- 放物線シュートの物理計算（斜方投射）
- グリーンリリース・シュートメーター（0.55秒スイートスポット）
- Web Audio API によるシンセサイズ効果音（ドリブル、スキーク、リング音、スウィッシュ、歓声）
- **ディフェンスなしの自由なソロシュート練習モード**

## 💡 学べるプログラミング概念
1. Three.js の基本（Scene, Camera, Renderer, Mesh, Material）
2. 高校物理の斜方投射（放物線運動と初速度の分解）
3. Web Audio API による音波合成（Oscillator, Noise, Filter）
4. イベントリスナーとアニメーションループ（requestAnimationFrame）
