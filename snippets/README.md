## 🚀 使い方

### 1. ブラウザで直接開く場合
各スクリプトフォルダ内の `index.html` をブラウザでダブルクリックして開くだけで、すぐに動作を確認できます。

### 2. Vite 開発サーバーで動かす場合
リポジトリのルートで `npm run dev` を実行し、ブラウザから各ページへアクセスできます。

## ➕ 新しいスクリプトを追加する手順
1. `snippets/02_xxx/` のように番号付きのフォルダを作成します。
2. フォルダ内に `index.html`, `style.css`, `main.js`, `README.md` を作成します。
3. `vite.config.js` の `input` にエントリーを追加します。
4. 本 `snippets/README.md` の一覧テーブルに追記します。
